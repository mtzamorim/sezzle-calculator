# Technical Assignment

Task requirements supplied by the candidate, reproduced in English. Personal recruitment
correspondence is omitted; spelling and formatting are normalized for readability.

## Objective

Build a full-stack calculator application with a React frontend and a backend
microservice. The frontend should consume the backend API to perform basic and advanced
arithmetic operations. Focus on clean design, maintainable code, and testable architecture.

## Functional requirements

**Operations:** addition, subtraction, multiplication, and division.
Optional: exponentiation, square root, and percentage.

**Frontend:** React, an intuitive input/result interface, input validation and error
handling, and responsive design with basic mobile support.

**Backend:** REST endpoints for calculator operations, validation and edge-case handling
(including division by zero and invalid data), and JSON results.

## Non-functional requirements

Clean, readable, idiomatic code in both layers. Unit tests covering key functionality in
both layers. Setup instructions, API usage, and design rationale. Optional Dockerfile for
full-stack deployment.

## Constraints

Frontend: React; TypeScript preferred. Backend: Go preferred.

## Deliverables

A Git repository containing frontend and backend code, README setup instructions, API
examples, design decisions/assumptions, unit tests, and coverage reports. Optional Dockerfile
to run the frontend and backend together.

## Instructions

AI tools are allowed. Aim for approximately 2-4 hours, prioritizing correctness, clarity,
and maintainability over extra features. Push the solution to a Git repository and share
the repository link. Share the prompts used in the work.
